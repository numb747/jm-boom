原作者已不再维护 JM Boom 桌面版，自本版本起由 [numb747/jm-boom](https://github.com/numb747/jm-boom) 继续维护。本版本在原版 v0.4.6 的基础上，合入了此前 fork 构建（fork-v0.4.6-3 ~ -7）的全部改动。

> 应用内更新已切换到本仓库的发布和签名密钥。原版 v0.4.6 及 fork-v0.4.6-x 构建无法通过应用内更新升级到本版本，请手动下载安装一次，之后即可正常应用内更新。

## 功能

- 阅读器底栏新增「收藏」按钮：阅读中点一下屏幕即可收藏 / 取消收藏，状态与详情页同步；未登录时直接在阅读器内弹出登录框，登录后自动完成收藏（已收藏的漫画不会被误取消） ([62236ba](https://github.com/numb747/jm-boom/commit/62236ba))
- 阅读器支持缩放（30%–400%）：Ctrl + 滚轮、Ctrl + / Ctrl − / Ctrl + 0，或在「阅读设置」中调整；竖向阅读和单页各自记住缩放比例 ([42305bd](https://github.com/numb747/jm-boom/commit/42305bd))
  - 竖向阅读：缩小后页面列变窄、一屏可看多页；缩放时保持当前阅读位置不跳动
  - 单页：缩小后居中显示，放大后可滚动查看，翻页后从页面顶部开始
- 双页阅读支持缩放，与单页共用缩放比例；左右两页改为贴合中缝显示 ([26272ae](https://github.com/numb747/jm-boom/commit/26272ae))

## 优化

- 应用内更新改为从本仓库检查和下载，并使用本仓库的签名密钥校验 ([38fcfde](https://github.com/numb747/jm-boom/commit/38fcfde))

## 修复

- 修复阅读器中在输入框打字或调节滑块时按方向键 / WASD 会触发翻页、按 Esc 关闭弹窗时会同时退出阅读器的问题 ([62236ba](https://github.com/numb747/jm-boom/commit/62236ba))
- 修复单页放大并滚动后，翻回该页时停留在上次滚动位置而不是页面顶部的问题 ([26272ae](https://github.com/numb747/jm-boom/commit/26272ae))
- 修复 Linux 上 WebKitGTK 2.54 中首页一直停在加载骨架屏、无法进入的问题：封面编号角标、阅读器浮层以及弹窗、抽屉遮罩的毛玻璃效果（`backdrop-filter`）会让 WebKit 合成线程陷入死循环，现已移除 ([312fecf](https://github.com/numb747/jm-boom/commit/312fecf), [1b5265b](https://github.com/numb747/jm-boom/commit/1b5265b))
- 修复部分 API 线路（如 `www.cdnhjk.net`、`www.cdnhth.net`）返回带 UTF-8 BOM 的响应导致登录失败、提示 `expected value at line 1 column 1` 的问题 ([12d3bed](https://github.com/numb747/jm-boom/commit/12d3bed))
- 修复 EmptyState 遮罩拦截点击的问题 ([03433f4](https://github.com/numb747/jm-boom/commit/03433f4))
- Linux 上通过 AUR、deb、rpm 安装时，应用内更新改为提示使用系统包管理器，避免覆盖由包管理器管理的程序文件 ([c12cc76](https://github.com/numb747/jm-boom/commit/c12cc76))
